Privacy Policy

Pitch Black Cyber, LLC | Product: PBC-GRC (grc.pitchblackcyber.com)

1. Overview & Commitment to Defense Data Protection

Pitch Black Cyber provides cybersecurity compliance software, automated System Security Plan (SSP) authoring tools, and cryptographic evidence vault management to Defense Industrial Base (DIB) contractors, aerospace organizations, and Managed Service Providers (MSPs). Because our customers operate under strict Department of Defense (DoD) regulatory standards—including FAR 52.204-21, DFARS 252.204-7012, NIST SP 800-171, and the Cybersecurity Maturity Model Certification (CMMC 2.0)—we have designed our data practices around strict tenant isolation, cryptographic verification, and minimal data collection.

2. Information We Collect

  • Customer Account & Identity Information: Contact name, corporate work email, direct phone number, organization name, CAGE Code, SAM.gov status, and in-scope user count.
  • Federated Authentication Claims: OAuth identity claims transmitted during Single Sign-On (Microsoft 365 / Entra ID or Google Workspace), including user principal names and cryptographic ID tokens. We never receive or store plaintext passwords.
  • Compliance Assessment & Evidence Data: System Security Plan (SSP) details, network boundary narratives, designated system owners, custom control implementation statements, and uploaded audit evidence artifacts stored in Google Cloud Storage.
  • Security & Audit Logs: Timestamps of control modifications, evidence uploads, export operations, IP addresses, and diagnostic telemetry necessary for CMMC Level 1 security audit trails.

3. How We Use Your Information

We process customer data exclusively to deliver and secure our compliance enclave services: 1. Provisioning isolated tenant enclaves in Google Cloud SQL and Google Cloud Storage. 2. Generating compliance deliverables (System Security Plans, SPRS matrices, and evidence packages). 3. Identity verification and multi-factor federated access control. 4. Providing technical support and solutions architect guidance. 5. Maintaining immutable audit logs and detecting unauthorized access.

Data Integrity Pledge: We DO NOT sell, monetize, rent, or trade your personal or organizational data. We DO NOT use your compliance narratives or evidence files to train public artificial intelligence models.

4. Multi-Tenant Data Isolation & Security Architecture

  • Cryptographic Evidence Integrity: Every evidence file uploaded to our Google Cloud Storage enclave is hashed client-side with SHA-256 before transit. Integrity hashes are verified upon retrieval to prevent tampering.
  • Tenant Partitioning: Database records are partitioned using PostgreSQL Row-Level Security (RLS) ensuring strict logical segregation between contractor enclaves.
  • Encryption in Transit & at Rest: All data in transit is encrypted using TLS 1.3. All persistent data in Google Cloud Storage and Google Cloud SQL is encrypted at rest using AES-256 with customer-managed or Google-managed keys.
  • Sub-processor Compliance: All cloud infrastructure hosting PBC-GRC services (Google Cloud Platform) maintains FedRAMP certifications, ISO 27001, and SOC 2 Type II compliance.

5. Third-Party Sub-processors

  • Google Cloud Platform (GCP): Cloud Run, Cloud SQL, Cloud Storage, and Cloud Identity Platform.
  • Microsoft Entra ID: Federated enterprise authentication for defense contractors utilizing Microsoft 365 GCC or Commercial.
  • Cloudflare: DNS routing, DDoS mitigation, and edge TLS termination.

6. Data Retention & Deletion

• Active Subscriptions: Retained for the duration of your active license agreement to support ongoing assessment baselines and C3PAO audits. • Upon Contract Termination: Within thirty (30) days of subscription termination or upon explicit written request, customer tenant databases and Google Cloud Storage evidence objects will be permanently purged in accordance with DoD 5220.22-M / NIST SP 800-88 sanitization guidelines. • Customer Backups: Administrators may export a complete JSON or Markdown archive of their entire assessment state and evidence manifest at any time via the top navigation bar.
